## Meet Upsun

**The software factory for AI-human workflows.** Upsun helps teams ship at the speed their agents work—with transparency, cost control, and people in the loop—then run it in production on the cloud and region they choose.

- **[Upsun Dispatch](https://upsun.com/dispatch/)**: run agent work as a defined workflow, with isolated steps, human approval where it counts, an [audit trail](https://upsun.com/dispatch/audit-trail/) of every run, and [real-time spend](https://upsun.com/dispatch/cost-transparency/) per run, workflow, and team.
- **[Upsun Cloud](https://upsun.com/cloud/)**: run your whole stack. Declare runtimes, frameworks, and services once in YAML, test on preview environments with real data, scale without downtime, and deploy the same config to AWS, Azure, GCP, IBM Cloud, or OVHcloud across [14 regions](https://upsun.com/features/multi-cloud-and-edge/).

Upsun Cloud is audited to SOC 2 Type 2, PCI DSS Level 1, and ISO/IEC 27001. Learn more in our [Trust center](https://upsun.com/trust-center/).

## Open source at Upsun

This organization is Upsun's official home for open source and shared code. You'll find:

- **Developer tooling**: the [Upsun CLI](https://github.com/upsun/cli), the [Upsun MCP server](https://github.com/upsun/upsun-mcp-server), and the [Upsun AI agent toolkit](https://github.com/upsun/ai)
- **Libraries and SDKs**: such as [upsun-sdk-php](https://github.com/upsun/upsun-sdk-php) and [whatsun](https://github.com/upsun/whatsun)
- **Examples and tools**: browse the [`upsun-example`](https://github.com/search?q=topic%3Aupsun-example+org%3Aupsun&type=repositories) and [`upsun-tools`](https://github.com/search?q=topic%3Aupsun-tools+org%3Aupsun&type=repositories) topics

Some repositories are community projects maintained by Upsun teams and are not covered by Upsun support. Check each repository's README for its status.

Upsun is built on open source, and we give back by sponsoring projects such as Symfony, DDEV, the Drupal Association, Doctrine, and PHPStan. [Discover our sponsored projects](https://upsun.com/community/open-source/).

### Contributing

- Found a bug or have an idea? Open an issue or a pull request on the relevant repository.
- Found a security issue? Please don't open a public issue. [Report it responsibly](https://upsun.com/trust-center/security/responsible-disclosure/).

## Our story

Since 2009, Upsun (formerly Platform.sh) has been removing backend complexity so developers can focus on building. Today, more than 16,000 developers run mission-critical apps on Upsun. [Learn more about us](https://upsun.com/about-us/).
